Designing for the Silver Generation

UX for the elderly requires a fundamental shift in empathy. We must account for physiological changes such as reduced visual acuity, diminished motor precision, and slower cognitive processing of new UI metaphors. My research focuses on using **Skeuomorphic Affordances** to bridge the gap between physical memory and digital action.

  • Target Sizing: Minimum 48dp for all touchpoints.
  • Contrast: Strict adherence to 7:1 ratio for text.
  • Haptics: Using vibration to confirm successful interaction.
